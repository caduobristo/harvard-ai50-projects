# Harvard CS50 AI Projects

This repository contains the projects I developed while taking **CS50’s Introduction to Artificial Intelligence with Python**, a course offered by **Harvard University**.

The course is divided into weekly modules, with a total of 7 weeks, each including one or more practical projects. All projects are submitted and automatically validated by CS50’s servers. Upon successful completion of the course, I will receive an official certificate from Harvard.

More information about the course can be found at: https://cs50.harvard.edu/ai/
